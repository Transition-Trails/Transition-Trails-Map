## Priority 6 — Schema Decision: Course__c.Program__c Field Type
ARCHITECTURAL — Hugh decision required before build
Current state: Program__c on Course__c is a Picklist field. Program names are duplicated as hardcoded picklist values rather than linked to live pmdm__Program__c records.
Problem: Changes to program names in Salesforce do not automatically update the course assignment. Trail OS cannot query by record ID — it must match by string.
Recommended change: Convert Program__c from a Picklist to a Lookup(pmdm__Program__c). This makes the relationship a proper record ID join.
## Impact
Changing a Picklist to a Lookup is a destructive schema change — existing picklist values on current records will be lost
The field must be deleted and rebuilt as a Lookup field
Only 24 Course records exist — re-assignment after conversion is minimal work
Trail OS server routes must be updated to query by Id rather than by name string
## Recommendation
Do this now while the data volume is small. The right time to fix a schema mistake is before records accumulate. If deferred, fuzzy name-matching remains as a workaround in Trail OS.
Decision required from Hugh: Confirm approach (convert now vs. accept fuzzy match temporarily) before either option is executed.
