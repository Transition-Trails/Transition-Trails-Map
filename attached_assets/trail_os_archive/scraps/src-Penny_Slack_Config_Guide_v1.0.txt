## 1.  Overview
Penny operates in Slack across three surfaces: direct messages, channel mentions, and the native Slack AI assistant panel. This guide covers the complete configuration of the Penny Slack app — from creating the app in the Slack API portal through OAuth scopes, Socket Mode, event subscriptions, slash commands, the AI assistant panel, and privacy best practices for running an AI assistant inside a Slack workspace.

## 3.  Create the Slack App
## 3.1  Create from app manifest (recommended)
The fastest and most reliable way to create the Penny Slack app is from a manifest — a YAML configuration file that sets all permissions, events, and features in one step.
1.  Go to api.slack.com/apps → click Create New App
2.  Choose From an app manifest
3.  Select the Transition Trails workspace
4.  Paste the manifest below (YAML tab) → click Next → Create

display_information:  name: Penny  description: Your AI Trail Assistant — coaching, quests, and career guidance  background_color: "#0F6E56"  long_description: >    Penny is your AI coaching companion on the Transition Trails. Why these scopes?
• app_mentions:read — Penny hears @Penny mentions in channels
• channels:history / groups:history / im:history — Penny can read context when mentioned in a thread
• chat:write — Penny can send messages
• chat:write.customize — Penny can send messages with a custom username and icon (used for formatted career review output)
• files:read — learners can upload PDF resumes for career review
• im:read + im:write + im:history — DM access (the primary coaching surface)
• users:read / users.profile:read — Penny can look up a Slack user's name and email for auto-registration
## 4.  Enable Socket Mode
Socket Mode allows Penny to receive real-time events from Slack without exposing a public webhook URL. This is the correct architecture for Replit-hosted apps and for workspaces that do not want to manage inbound firewall rules.
## 4.1  Generate the App-Level Token
Socket Mode requires a special App-Level Token (different from the Bot Token). This token starts with xapp- and is set as SLACK_APP_TOKEN in your environment variables.
1.  In your Penny app configuration → Settings → Basic Information
2.  Scroll to App-Level Tokens → Generate Token and Scopes
3.  Token name: Penny Socket Mode
4.  Add scope: connections:write
5.  Click Generate → copy the xapp-... token immediately (it is only shown once)
6.  Add to Replit Secrets as SLACK_APP_TOKEN
Token visibility warning
• The App-Level Token is only displayed once at generation time.
• If you miss copying it, you must regenerate it — the old token is invalidated.
• Never commit this token to git or share it outside Replit Secrets.
## 4.2  Verify Socket Mode is enabled
1.  Settings → Socket Mode → toggle Enable Socket Mode to On
2.  Confirm "Socket Mode is enabled" message appears in green

## 5.  Bot Identity & Display
How Penny appears to learners in Slack matters. A consistent identity builds trust and helps learners understand they are talking to an AI companion, not a generic bot.
## 5.1  Bot name and display settings
1.  Features → App Home → scroll to Bot User
2.  Display name: Penny
3.  Default username: penny
4.  Always show my bot as online: ✓ Enabled
Why "always online" matters
• "Always online" means Penny shows a green dot in Slack at all times.
• This signals to learners that Penny is available and reduces hesitation to message.
• The actual response time depends on Gemini — typically under 3 seconds.

## 7.  Interactivity & Slash Commands
## 7.1  Interactivity
Interactivity must be enabled for Penny to handle file uploads (PDF career review) and any future interactive components such as buttons or select menus in Block Kit messages.
1.  Features → Interactivity & Shortcuts → toggle Interactivity to On
2.  Request URL: leave blank (Socket Mode handles interactivity without a URL)
3.  Save changes
## 7.2  Slash command: /penny
The /penny slash command gives learners a fast entry point to Penny from any channel or DM without needing to @mention her.
1.  Features → Slash Commands → Create New Command
2.  Command: /penny
3.  Request URL: leave blank (Socket Mode handles slash commands)
4.  Short description: Talk to Penny — your AI Trail Assistant
5.  Usage hint: [your message or question]
6.  Escape channels, users, and links: leave unchecked
7.  Save
What /penny does
• /penny [message] in a channel — Penny responds in a thread. Keeps the channel clean.
• /penny with no message — Penny responds with a short welcome and asks what's on the learner's mind.
• /penny in a DM — same as sending a message directly to Penny.
## 8.  Slack AI Assistant Panel
The AI assistant panel is the Penny icon that appears in the top-right corner of Slack when users are in your workspace. It is a Slack-native feature that surfaces AI apps alongside the message window. Penny is already appearing there — this section covers how to customise it.
## 8.1  What the panel is and is not
It IS

A discovery surface for learners who haven't messaged Penny yet
A full coaching surface — Penny has no learner context in the panel
A shortcut to show "How to use Penny?" onboarding content
A replacement for DM coaching or Penny Mobile
Channel-scoped — it shows in the context of whatever channel is open
Personalised — no individual learner profile is injected
A great place for quick FAQ answers (how does questing work?)
Suitable for career review, quest submission, or coordinator tasks
## 8.2  Customise "How to use Penny?"
Currently the panel shows the default Slack onboarding text. Replace it with Penny-specific content so learners know exactly what she can do.
1.  In api.slack.com/apps → select Penny → Features → App Home
2.  Scroll to Show Tabs → enable the Home Tab
3.  The AI assistant "How to use Penny?" prompt is controlled by your App Home home_tab_enabled configuration
4.  In your Bolt.js app, register an app_home_opened handler (see code below)
## Recommended App Home content (Bolt.js handler)
app.event('app_home_opened', async ({ event, client }) => {  await client.views.publish({    user_id: event.user,    view: {      type: 'home',      blocks: [        {          type: 'header',          text: { type: 'plain_text', text: 'Welcome to Penny 👋', emoji: true },        },        {          type: 'section',          text: {            type: 'mrkdwn',            text: '*A penny for your thoughts — and your career.*\n\nI\'m Penny, your AI coaching companion on the Transition Trails. Here\'s what I can do for you:',          },        },        {          type: 'section',          text: {            type: 'mrkdwn',            text: ':brain: Coaching — :dart: Quests — :briefcase: Career Review — :busts_in_silhouette: Mobile App',          },        },        {          type: 'section',          text: {            type: 'mrkdwn',            text: ':speech_balloon: *Ready? Send me a direct message to get started.*',          },        },      ],    },  });});
AI assistant panel best practices
• Keep the panel content short — 4-5 bullet points maximum. Learners scan, they don't read.
• Always end with a clear CTA: "Send me a direct message to get started."
• Do not try to do coaching inside the panel. Its job is to route learners to the right surface.
• Update the panel content whenever Penny's capabilities change.

## 10.4  Learner first-contact flow
When a learner sends their first DM to Penny, this is what happens automatically:
1.  Penny receives the message.im event via Socket Mode
2.  She checks the interaction_logs table for this Slack user ID
3.  If the user is unknown: auto-registration fires — a new learner_profiles row is created with trail: guided_trail
4.  Penny greets them as a new learner and asks for their name and goal
5.  The learner is now registered and will receive personalised coaching on all subsequent messages
Auto-registration is intentional
• Any unknown Slack user who messages Penny is automatically registered as a guided_trail learner.
• Angela can reassign them to a different trail in the Admin Dashboard → Learners.
• The learner does not need to complete any form or registration step.

## 11.3  Transparency with learners
Learners should know they are interacting with an AI assistant and that their conversations are stored. Include this in the cohort welcome message and in the Penny App Home description.
Recommended transparency statement
• Penny is an AI coaching assistant. Your conversations with her are stored to help Angela support you.
• Angela can see your messages, quest responses, and career review summaries in the coaching dashboard.
• Your data is never shared outside of Transition Trails. You can ask Angela to delete your Penny history at any time.
## 11.4  Minimum required scopes — principle of least privilege
The manifest in Section 3 requests only the scopes Penny needs. Do not add scopes beyond what is listed. Specifically:
Scopes to avoid
• channels:manage / groups:manage — Penny should not be able to create, archive, or modify channels
• users:write — Penny should not be able to update user profiles
• files:write — Penny should not be able to upload files (only read PDFs that learners send her)
• admin:* scopes — never required and should never be granted
• Any user token scopes — Penny uses a bot token only. User tokens act as Angela and are a significant security risk.
## 11.5  Signing secret validation
The SLACK_SIGNING_SECRET is used to verify that incoming events actually come from Slack and have not been tampered with. Bolt.js handles this automatically when the signing secret is present in the environment.
Security checklist
• SLACK_SIGNING_SECRET is set in Replit Secrets — not hardcoded in source
• SLACK_BOT_TOKEN is set in Replit Secrets — never in a .env file committed to git
• SLACK_APP_TOKEN is set in Replit Secrets — only shown once at generation
• Socket Mode is enabled — no public webhook URL is exposed to the internet
• Token rotation is disabled by default — enable it if you suspect a token has been compromised

## 12.2  Interpreting the Bolt.js startup log
When the api-server starts successfully, you should see these log lines in the Replit console:
{"level":"info","msg":"Bolt app is running (Socket Mode)"}{"level":"info","msg":"API server listening on port 8080"}{"level":"info","msg":"Database migrations complete"}{"level":"info","msg":"Weekly report cron scheduled: Friday 16:00 UTC"}
Common startup errors
• "Error: An API error occurred: invalid_auth" — SLACK_BOT_TOKEN is wrong or missing. Re-copy from OAuth & Permissions.
• "Error: An API error occurred: not_allowed_token_type" — SLACK_APP_TOKEN is missing or using the bot token instead of the xapp- app token.
• "SocketModeClient: Unable to connect" — Socket Mode is not enabled in the app configuration.
• "Gemini quota exhausted" — GEMINI_APP_KEY is at the 20 req/day free tier limit. Response resumes tomorrow.
## 13.  Ongoing Maintenance
## 13.1  Token rotation
Slack bot tokens do not expire by default. However, if you suspect a token has been compromised:
1.  api.slack.com/apps → Penny → OAuth & Permissions → Revoke All OAuth Tokens
2.  Reinstall the app to the workspace to generate a new token
3.  Update SLACK_BOT_TOKEN in Replit Secrets
4.  Restart the api-server
## 13.2  Adding Penny to new channels
As new cohort channels are created, invite Penny to each one:
In the new channel: type /invite @Penny
Verify Penny posts the join confirmation message
No code changes needed — Bolt.js listens for events from all channels where Penny is a member
## 13.3  Integration staleness alerts
Penny includes a built-in hourly poller that checks whether integrations (Slack, Notion, GitHub) have sent a recent event. If an integration goes silent for more than 24 hours, Penny posts an alert to PENNY_ADMIN_SLACK_CHANNEL. This is your early warning system for broken webhooks or expired credentials.
## 13.4  Weekly report delivery
Every Friday at 4 PM UTC (default), Penny posts a cohort health report to PENNY_ADMIN_SLACK_CHANNEL. To change the schedule:
Variable
Default
Example change
PENNY_REPORT_DAY
5 (Friday)
1 = Monday, 3 = Wednesday, 5 = Friday
PENNY_REPORT_HOUR
16 (4 PM UTC)
11 = 11 AM UTC = 6 AM CDT in summer
CDT time offset
• Central Daylight Time (CDT) is UTC-5.
• 16:00 UTC = 11:00 AM CDT — the report arrives at 11 AM Dallas time on Fridays.
• Set PENNY_REPORT_HOUR=16 to keep this schedule.
## 13.5  Clearing a learner's Penny memory
If a learner's context becomes stale or incorrect, Angela can clear their memory from the admin dashboard. This deletes all interaction_logs rows for that learner. Penny will start the next conversation fresh.
1.  Admin Dashboard → Learners → select the learner
2.  Scroll to Conversation History → click Clear Memory
3.  Confirm the dialog
4.  The learner's next message to Penny will be treated as a clean-slate conversation
Clear Memory is permanent
• Clearing memory deletes all interaction_logs rows for that learner.
• This cannot be undone from the admin UI.
• Quest history, career review sessions, and gamification records are NOT deleted — only the conversation memory window is cleared.
