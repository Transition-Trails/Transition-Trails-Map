## 1.  The Brand Promise
"A penny for your thoughts."
Penny is Transition Trails Academy&apos;s adaptive AI coaching companion — the voice that helps career changers, military veterans, and underrepresented professionals think through the hard moments on their path to becoming Salesforce Administrators. She doesn&apos;t give answers. She helps learners find them.
Penny operates across three surfaces: a mobile progressive web app, a Slack bot, and an admin intelligence dashboard. Every surface reflects the same core belief: the best coaching asks better questions.
## 2.  The Problem We Are Solving
Transition Trails equips career changers with Salesforce skills through structured cohort programs. But the hardest moments — the late-night blocker, the interview anxiety, the "does my resume even make sense?" spiral — happen outside of scheduled coaching sessions.
Without on-demand support, three things break:
Learners stall and lose momentum when they can&apos;t get unstuck on their own timeline
Coaches are overwhelmed with repetitive unblocking work instead of high-value mentorship
Program administrators have no real-time visibility into cohort health, engagement, or risk
Hugh Richardson is the proof of concept. A Cohort 0 graduate who went from certified-and-stuck to employed — Penny was the bridge he needed between "I passed the exam" and "I got the job."
## 3.  Penny&apos;s Solution
Penny v2 is a production-quality POC with a complete mobile PWA, a live Slack bot, a 12-template quest system, a career review engine, and a full admin intelligence dashboard. The system is built, tested, and running.

## 4.  What Has Been Built (POC v2)
Build Status: Production-Quality POC
The Penny POC v2 is substantially ahead of spec. The backend is feature-complete with 1,100+ automated tests across 38 test files. The mobile PWA is built and deployed on Replit. This is not a prototype — it is a working system.
## System Architecture
Backend Runtime
Node.js ESM · Express 5 · TypeScript strict mode throughout
Database
PostgreSQL via Drizzle ORM (Supabase) · 12 tables · auto-migrations at startup
AI Engine
Google Gemini 2.5 Flash (gemini-2.5-flash-preview-05-20) with 7-layer system prompt construction
Mobile PWA
React 18 + Vite · Shadcn UI · TanStack Query · Wouter routing · SSE streaming chat
Slack Bot
Bolt.js Socket Mode — no public webhook required
Notion
Project management · sprint tasks · training documentation · sprint briefs (Notion API)
API Contract
OpenAPI 3.0 spec → Orval codegen → type-safe React Query hooks
Logging
Pino structured JSON throughout; no bare console.log
Testing
Vitest · 1,100+ tests · Gemini mocked · runs in ~74s · CI via GitHub Actions

## The Ask
What We Need to Scale Penny Beyond the POC
Engineering capacity to extend the Replit POC into a production-grade deployment with Salesforce Experience Cloud integration
Design capacity to expand the Figma design system into a full component library and refine the mobile PWA UX
Partnership support to pilot Penny with 2-3 additional nonprofit cohorts alongside Transition Trails Cohort 1
AI infrastructure budget for Gemini API costs at scale (estimated $200-400/month for 50 active learners)
Strategic advisors with experience in workforce development technology and nonprofit technology grants
Why Now
The Penny POC v2 proves the concept at a level of technical maturity that most early-stage nonprofit tools never reach. 1,100+ tests, a live mobile app, a running Slack bot, and a complete admin dashboard are not demo artifacts — they are a foundation. The question is no longer "can this be built?" The question is "how fast can we get this to every cohort that needs it?"
